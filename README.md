A Node 22 program that writes exactly one letter — A, for coffee — to entry.txt, the entry for make.fun's One Letter: Coffee or Tea bounty. The brief allows nothing else: one letter, no word, no explanation, no punctuation. Coffee is the pick: the fuller, more alive answer for a builder's day, the first cup before the first line of code.

## Run it

```sh
node main.ts
```

The output directory defaults to `/output`; set `MAKEFUN_OUTPUT_DIR` or pass `--output <dir>` to write `entry.txt` elsewhere.
